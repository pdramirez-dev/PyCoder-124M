# Python Code Datasets on Hugging Face

This list was checked on 2026-10-29 using the Hugging Face API (`/api/datasets`) and dataset viewer (`datasets-server`). A sample of `Avelina/python-edu-cleaned` was downloaded; its revision and shards are recorded in `data/raw/python-edu.json`. Row counts and sizes come from the viewer; for large datasets it may convert only part of the data, so treat them as approximate.

Access key: **open** = direct download without accepting terms; **gated** = accept the terms on the website and sign in (`hf auth login`); **IDs only** = the dataset contains `blob_id`, and content must be downloaded separately from Software Heritage (S3, requiring AWS credentials).

## Caveats

- The license declared on Hugging Face does not replace each source file's license. Preserve `repo_name`, `path`, and per-file license when available, and review each dataset's terms before training.
- Several corpora overlap (all derive from GitHub/The Stack). If combined, deduplicate across them.
- To decontaminate evaluation, exclude benchmarks such as HumanEval and MBPP from the corpus.

## Required Volume

100M tokens (the first-stage target) are approximately 350–450 MB of Python code. A sample of `Avelina/python-edu-cleaned` is sufficient; downloading the full dataset is unnecessary.
